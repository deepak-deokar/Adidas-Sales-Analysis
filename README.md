# Adidas Sales Analysis

## Introduction
This repository contains a comprehensive analysis of Adidas's sales data in the United States. The primary goal of this project is to uncover actionable insights that can inform strategic business decisions, optimize product portfolios, and identify opportunities for market expansion. By analyzing sales performance, profitability, and customer behavior, we aim to provide a clear and data-driven understanding of Adidas's market position.

## Repository Contents
- **Adidas Dashboard.pbix:** An interactive Power BI dashboard that provides a visual representation of sales data, key performance indicators (KPIs), and trends. This dashboard allows for dynamic exploration of the data.
- **Adidas Sales Analysis File.html:** A detailed report summarizing the findings from the sales analysis, formatted for easy web viewing. This report outlines the methodology, key insights, and recommendations.
- **Adidas Sales Analysis File.ipynb:** A Jupyter notebook that contains all the Python code used for the data analysis. This includes data cleaning, manipulation, exploratory data analysis (EDA), and visualization.
- **Adidas US Sales Datasets.xlsx:** The raw dataset used for the analysis, containing sales figures across various product lines, regions, and sales channels.

## Technologies Used
- **Power BI:** Utilized for creating interactive and visually appealing dashboards to explore sales trends and KPIs.
- **Python:** The primary programming language used for data cleaning, analysis, and visualization. Key libraries include:
  - **pandas:** For data manipulation and analysis.
  - **numpy:** For numerical operations.
  - **matplotlib & seaborn:** For data visualization.
- **Jupyter Notebook:** The development environment for writing and executing Python scripts.

## Analysis Overview
The analysis covers several key areas to provide a holistic view of Adidas's sales performance:
- **Sales Performance:** Analysis of sales by product, region, and sales channel to identify top-performing areas.
- **Profitability Analysis:** Evaluation of operating profit and profit margins to determine the most profitable products and regions.
- **Sales Channel Efficiency:** Assessment of the effectiveness of different sales methods (e.g., in-store, online) in driving revenue.
- **Price Optimization:** Analysis of sales data by price range to identify optimal pricing strategies.
- **Time Series Analysis:** Forecasting future sales trends using the Prophet model to support inventory and marketing planning.

## Key Insights
- **Top-Performing Products:** Men's Street Footwear and Men's Athletic Footwear are the highest-selling products, indicating a strong market for men's footwear.
- **Regional Performance:** The Northeast and West regions are the most significant contributors to total sales, suggesting these are key markets for Adidas.
- **Sales Channel Effectiveness:** In-store sales are the most profitable channel, highlighting the importance of the retail footprint.
- **Profitability:** The most profitable products are Men's Street Footwear and Women's Apparel, which should be prioritized in marketing and inventory decisions.
